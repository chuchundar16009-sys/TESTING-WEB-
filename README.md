# Velora-style Finance Website

A polished, responsive static frontend inspired by modern fintech/crypto dashboards.

## Included
- Overview dashboard
- Add Funds page
- Withdraw page
- Support / FAQ
- Profile page
- Privacy Policy
- Terms of Service
- Responsive mobile navigation
- Light/dark theme toggle
- Copy-to-clipboard demo
- No framework or build step required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the contents of this folder to the repository root. Keep `index.html` in the root, then enable GitHub Pages from the repository's Pages settings.

## Important
This is a frontend template. The deposit/withdraw actions are demo buttons. Connect your own authenticated backend/payment provider before using real transactions. Replace placeholder contact details and legal text with your actual business information.
